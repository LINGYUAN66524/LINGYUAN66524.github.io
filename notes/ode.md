## 一、基本概念

含有未知函数及其导数的方程，称为**微分方程**。例如

$$\frac{\mathrm{d}y}{\mathrm{d}x} = 2x$$

它的通解是 $y = x^2 + C$，其中 $C$ 为任意常数。

### 1.1 阶与线性

- **阶**：方程中出现的最高阶导数的阶数
- **线性**：未知函数及其各阶导数都是一次的，系数只与自变量有关

$n$ 阶线性微分方程的一般形式：

$$a_n(x)\,y^{(n)} + \cdots + a_1(x)\,y' + a_0(x)\,y = f(x)$$

## 二、一阶微分方程

### 2.1 可分离变量

若方程能写成 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y)$，则可分离为

$$\int \frac{\mathrm{d}y}{g(y)} = \int f(x)\,\mathrm{d}x$$

### 2.2 一阶线性方程

形如

$$y' + P(x)\,y = Q(x)$$

的通解为

$$y = e^{-\int P\,\mathrm{d}x}\left(\int Q\,e^{\int P\,\mathrm{d}x}\,\mathrm{d}x + C\right)$$

### 2.3 常见类型对照

| 类型 | 判别特征 | 解法 |
| --- | --- | --- |
| 可分离变量 | 能写成 $f(x)g(y)$ | 两边积分 |
| 齐次方程 | $\dfrac{\mathrm{d}y}{\mathrm{d}x} = \varphi\!\left(\dfrac{y}{x}\right)$ | 令 $u = y/x$ |
| 一阶线性 | $y' + P(x)y = Q(x)$ | 常数变易 / 积分因子 |
| 伯努利方程 | $y' + P(x)y = Q(x)y^n$ | 令 $z = y^{1-n}$ |

## 三、可降阶的高阶方程

1. $y^{(n)} = f(x)$：逐次积分 $n$ 次
2. $y'' = f(x, y')$：令 $p = y'$，化为关于 $p$ 的一阶方程
3. $y'' = f(y, y')$：令 $p = y'$，并注意 $y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$

## 四、常系数线性方程

### 4.1 二阶齐次

$$y'' + py' + qy = 0$$

对应特征方程 $\lambda^2 + p\lambda + q = 0$，按判别式 $\Delta = p^2 - 4q$ 分三种情形：

- $\Delta > 0$：两个不等实根，$y = C_1e^{\lambda_1 x} + C_2e^{\lambda_2 x}$
- $\Delta = 0$：重根，$y = (C_1 + C_2x)e^{\lambda x}$
- $\Delta < 0$：共轭复根 $\alpha \pm \beta i$，$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$
